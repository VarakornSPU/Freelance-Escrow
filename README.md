 <img width="785" height="526" alt="image" src="https://github.com/user-attachments/assets/b9b9570a-53e3-4fe7-825e-0a876e224157" />

3.	ฝากเงินเข้าสัญญา ต้องเลือก ID ของโปรเจคให้ถูกต้องและโอนยอดเงินตรงตามยอด

5.	เมื่อผู้ว่าจ้างตรวจเช็คงานแล้วให้ผ่านก็เลือกโปรเจค ID ให้ถูกต้องและ กดอนุมัติและโอนเงินให้ Freelance
 <img width="940" height="234" alt="image" src="https://github.com/user-attachments/assets/01b285a0-2bda-4e9f-a628-4aea90d2364d" />

6.	แต่ถ้าผู้ว่าจ้างตรวจงานแล้วรู้สึกว่ามันไม่ถูกต้อง มีข้อพิพาท ก็สามารถแจ้งข้อพิพาทไปให้ Admin ได้
 <img width="940" height="249" alt="image" src="https://github.com/user-attachments/assets/525db3f1-069b-4162-a6eb-efc115518bc4" />

7.	ในบัญชีของ Admin จะมี ปุ่มให้แอดมินตัดสินใจว่า ใครเป็นฝ่ายผิดหรือถูก ถ้า Admin เลือกที่จะให้ผู้ว่าจ้างเป็นฝ่ายถูก สถานะของโปรเจคนั้นจะถูกเปลี่ยนจาก Disputed (มีข้อพิพาท) เป็น Refunded (คืนเงินแล้ว) แต่ถ้า Admin เลือกให้ Freelance เป็นฝ่ายถูก สถานะของโปรเจคก็จะถูกเปลี่ยนจาก Disputed (มีข้อพิพาท) เป็น Completed (เสร็จสิ้น)
